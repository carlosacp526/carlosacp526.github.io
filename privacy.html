Política de Privacidad

App: Poketubi Clips Uploader Vigente desde 19 sep 2026
Sobre esta app. Poketubi Clips Uploader es una herramienta interna usada por el equipo de Poketubi para publicar clips destacados de nuestras transmisiones de Pokémon competitivo (Twitch) directamente en la cuenta oficial de TikTok @poketubi, mediante la API oficial de TikTok (Login Kit + Content Posting API).

1. Datos que maneja la app

Al conectar la cuenta de TikTok de Poketubi mediante Login Kit, la app recibe únicamente:

  • Un token de acceso (access token) y token de actualización (refresh token) de OAuth, asociados a la cuenta @poketubi.
  • Datos básicos públicos de esa cuenta (nombre de usuario, ID de cuenta) necesarios para confirmar la conexión correcta.

La app no recolecta datos de espectadores, seguidores ni de ninguna persona que no sea el staff que opera la cuenta de Poketubi.

2. Para qué se usan

Los tokens se usan exclusivamente para publicar videos (clips) en la cuenta de TikTok de Poketubi a través de la Content Posting API oficial de TikTok. No se usan para leer mensajes privados, seguidores, ni ninguna otra información de la cuenta.

3. Almacenamiento y seguridad

Los tokens se guardan de forma privada (variables de entorno / almacenamiento cifrado local), nunca en repositorios públicos ni se comparten con terceros.

4. Revocar el acceso

El equipo de Poketubi puede desconectar la app en cualquier momento desde la configuración de aplicaciones conectadas de TikTok, lo que invalida los tokens de inmediato.

5. Terceros

No vendemos, alquilamos ni compartimos datos con terceros. La única integración es con la API oficial de TikTok for Developers.
